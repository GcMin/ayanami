# 阅读器规范

## 1. 阅读会话

阅读器输入为稳定的 `chapterId` 和页面描述列表。在线图片、缓存图片与完整下载图片只在 `PageRepository` 层有差异，渲染层接收统一的可解码图片句柄和页面元数据。

启动顺序：

1. 读取作品级设置，否则读取全局设置；
2. 恢复最后章节、页码和页内偏移；
3. 优先加载本地文件，否则解析在线请求；
4. 渲染当前页后预加载相邻页；
5. 按节流策略保存进度。

## 2. 阅读方向

```dart
enum ReadingDirection {
  vertical,
  webtoon,
  leftToRight,
  rightToLeft,
}
```

- `vertical`：分页图片纵向连续排列，可配置间距。
- `webtoon`：纵向无缝排列，默认 0 间距和适应宽度。
- `leftToRight`：水平翻页，左侧为上一页。
- `rightToLeft`：水平翻页，右侧为上一页。

方向影响翻页和点击区域，不改变章节列表的时间排序。

## 3. 缩放模式

```dart
enum ReaderScaleMode {
  originalSize,
  fitWidth,
  fitHeight,
  fitScreen,
  smartFit,
}
```

### 设置入口与持久化

阅读器控制层提供“页面适配”面板，至少显示：原始尺寸、适应宽度、适应高度、适应屏幕和智能适应。切换后立即重新布局当前页，不重新下载图片，也不修改阅读进度。

用户可以选择设置作用域：

```text
仅本次阅读会话
当前漫画
所有漫画的默认值
```

优先级为“本次会话 > 当前漫画 > 全局默认”。作品级偏好以本地 `mangaId` 保存；不能由 JS 源覆盖。屏幕旋转、应用重启和章节切换后按照该优先级恢复。

设图片尺寸为 `(Iw, Ih)`，扣除安全区域和控制栏后的可用视口为 `(Vw, Vh)`：

### 原始尺寸

```text
scale = deviceLogicalPixelsPerImagePixel
```

目标是 1 个图片像素对应 1 个设备逻辑像素。允许双向拖动与缩放。双击恢复原始尺寸。

### 适应宽度

```text
scale = Vw / Iw
displayHeight = Ih * scale
```

保持宽高比，不横向裁切。高度超出视口时纵向滚动。Webtoon 默认使用该模式。

### 适应高度

```text
scale = Vh / Ih
displayWidth = Iw * scale
```

保持宽高比，不纵向裁切。宽度超出视口时允许横向拖动。

### 适应屏幕

```text
scale = min(Vw / Iw, Vh / Ih)
```

整页可见，允许留白，不裁切。

### 智能适应

建议规则：

```text
若 direction == webtoon             -> fitWidth
否则若 Ih / Iw >= 2.2               -> fitWidth
否则若为横向翻页且页面可完整显示      -> fitScreen
否则                                 -> fitHeight
```

阈值 `2.2` 为可配置迁移点，不是领域常量。横竖屏变化后重新判断；用户手动选择后本会话不再自动切换。

## 4. 缩放与手势

默认配置：

| 项目 | 默认值 |
|---|---:|
| 最小缩放 | `0.5x` |
| 最大缩放 | `5.0x` |
| 双击缩放 | `2.0x` |
| 普通纵向间距 | `4 dp` |
| Webtoon 间距 | `0 dp` |
| 翻页间距 | `0 dp` |

```dart
class ReaderLayoutPreference {
  final ReaderScaleMode scaleMode;
  final ReadingDirection direction;
  final double minScale;
  final double maxScale;
  final double doubleTapScale;
  final double pageSpacingDp;
  final CropMode cropMode;
}
```

手势优先级：

1. 多指缩放；
2. 放大后的平移；
3. 阅读方向滚动/翻页；
4. 单击区域操作；
5. 长按快捷菜单。

放大状态下，拖到边缘后才允许将剩余手势传递给翻页容器，防止误翻页。旋转屏幕后保持当前页面身份，页内位置以归一化坐标恢复。

## 5. 页面裁边

```dart
enum CropMode { none, autoLightBorder, autoDarkBorder, manual }
```

- 裁边只影响视图变换，不修改原图。
- 自动裁边在后台计算，并使用图片哈希、算法版本和设置生成缓存键。
- 识别置信度不足时不裁边。
- 手动裁边参数使用相对坐标 `[0, 1]`，适用于同一作品或单页，由用户选择作用域。

## 6. 预加载、后续页缓存和内存

“内存预加载”和“磁盘自动缓存”是两个独立层次：

- 内存预加载用于提前解码临近页面，使翻页平滑；系统可以在内存压力下立即释放。
- 磁盘自动缓存用于提前获取当前章节后续页面，允许 LRU 清理，不代表正式下载完成。

### 6.1 内存预加载

- 当前页为最高优先级，默认向前 1 页、向后 2 页。
- Webtoon 可按距视口的像素距离预加载，而非固定页数。
- 图片先读取尺寸和采样解码，避免始终按原分辨率展开。
- 内存警告时立即释放不可见原图、缩略缓存和远端响应体。
- 预加载失败不弹全局错误；用户实际到达该页时再显示可重试占位。

### 6.2 当前章节后续页磁盘缓存

> 当前产品迭代采用 ADR-015：打开章节后可后台预加载当前章节全部页面；本节原有的有限滑动窗口作为后续资源受限模式保留，设置关闭预加载时不发起自动请求。

```dart
class ChapterReadAheadPreference {
  final bool enabled;              // 默认 true
  final int nextPageCount;         // 默认 5，允许 1..20
  final bool allowMeteredNetwork;  // 默认 false
}
```

当用户稳定阅读到页 `i` 时，缓存协调器确保同一章节 `[i + 1, i + nextPageCount]` 范围内尚未存在的页面进入低优先级缓存队列。用户继续阅读后窗口向前滑动；不自动跨章节缓存。

规则：

- 已存在内存、磁盘缓存或正式下载的页面不重复请求。
- 当前可见页和用户主动请求始终优先于后续页缓存。
- 默认仅非计量网络执行；用户可允许移动网络或完全关闭。
- 应用进入后台、源被禁用、章节离开、空间低于阈值或任务取消时停止创建新预读请求。
- 已完成的缓存文件继续由 LRU 管理；缓存失败不标记章节下载失败。
- 需要短期签名 URL 时，每页发起请求前仍按源规范解析有效请求。
- 若用户选择“下载当前章节”，已验证缓存可以提升为正式下载文件或被复用，不能无理由重复传输。

## 7. 进度保存

保存字段：章节、页索引、页内归一化偏移、阅读方向、完成状态和时间。

- 页面稳定显示 500 ms 后可写入候选进度。
- 连续滚动最多每 2 秒持久化一次；应用进入后台时立即刷新。
- 到达最后一页不自动标记完成，只有页面可见达到阈值或用户翻到下一章时标记。
- 写入必须幂等；较旧时间戳不得覆盖较新进度。

## 8. 控制层

最小控制项：

- 返回；
- 当前章节与页码；
- 上/下一章；
- 阅读方向；
- 页面适配（含适应宽度、适应高度等缩放模式与保存作用域）；
- 当前章节后续页缓存开关和页数；
- 旋转锁定；
- 裁边；
- 亮度覆盖；
- 下载当前章节；
- 页面重试和错误详情。

控制栏自动隐藏不得影响系统返回手势和无障碍焦点。

## 9. 错误与占位

- 单页失败显示页内占位，不使整章退出。
- 图片格式不支持时显示 MIME、尺寸和脱敏来源，允许重新解析请求。
- 源已禁用但本地文件存在时继续离线阅读。
- 网络断开时只尝试本地文件；恢复网络后由用户或明确策略重试。
- 页面列表变化时，以稳定页面 ID 或图片哈希对齐；无法对齐则保留页索引并提示。

## 10. 验收场景

- 超长 Webtoon、超宽跨页、单页小图、透明图、动态图首帧和损坏图片。
- 左到右/右到左点击区域与滑动方向正确。
- 五种缩放模式在横竖屏、刘海和系统栏变化下无裁切错误。
- 页面适配模式可在阅读中切换，并按本次会话、当前漫画或全局默认正确恢复。
- 当前章节自动缓存后 5 页，窗口随阅读前移且不跨章节；关闭或计量网络限制时不发起预读。
- 200 页章节滚动无明显持续内存增长。
- 杀进程、旋转、切后台和离线重启后恢复到同一阅读位置。
