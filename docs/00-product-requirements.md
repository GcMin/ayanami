# 产品需求与范围

文档状态：已确认  
版本：1.1  
日期：2026-08-20

## 1. 产品定义

Ayanami 是一款 **Android 优先、本地优先的漫画阅读器**。产品体验参考 Suwayomi 的多漫画源与本地书架能力，但 Ayanami 不要求用户额外部署服务器。

应用不经营、不托管漫画内容。用户自行安装 JavaScript 漫画源，宿主负责执行源规则、聚合结果、维护书架、阅读进度、缓存和下载。

核心目标是：

```text
安装漫画源 -> 浏览/搜索 -> 查看详情 -> 加入书架 -> 阅读 -> 下载/离线
```

## 2. 首页信息架构

应用启动后直接进入首页，使用底部导航提供三个一级入口：

### 2.1 书架

默认首页。

职责：

- 展示用户已加入书架的漫画；
- 展示最后阅读章节和阅读进度；
- 展示未读章节数量；
- 展示本地下载状态；
- 支持排序、筛选、批量选择和批量下载；
- 点击漫画直接进入宿主详情页或继续阅读。

书架是宿主本地状态，不属于任何漫画源。

### 2.2 漫画源

漫画源页面同时承担 **源管理** 和 **内容发现** 两类职责。

页面至少包含：

- 已安装漫画源列表；
- 启用/禁用状态；
- 添加 JS 源；
- 删除、更新、查看错误；
- 当前源浏览；
- 单源搜索；
- 多源聚合搜索；
- 源提供的热门、最新、分类、筛选器等可选入口。

“发现/搜索”不再单独占据一级导航。

### 2.3 设置

设置页只包含应用级偏好：

- 阅读方向和页面适配；
- 图片预加载和缓存策略；
- 下载并发、网络约束与存储；
- 外观、语言；
- 日志与诊断；
- 关于应用。

漫画源安装、启停和升级不得塞入设置页。人类已经发明过一次层级菜单灾难，没有必要在漫画阅读器里复刻。

## 3. JavaScript 漫画源

### 3.1 目标

一个漫画源插件负责把某个站点或内容服务转换为统一数据模型。

基础调用：

```text
search()
getMangaDetails()
getChapters()
getPages()
```

可选调用：

```text
getPopular()
getLatest()
getFilters()
```

### 3.2 宿主与插件边界

JS 插件负责：

- 构造请求；
- 解析网页或 JSON；
- 生成漫画、章节、页面标准对象。

宿主负责：

- 网络请求执行；
- 域名与权限检查；
- Cookie 隔离；
- JS 生命周期；
- 搜索结果聚合；
- 书架；
- 本地数据库；
- 阅读器；
- 图片缓存与下载；
- 日志和错误展示。

插件不得直接访问 Flutter Widget、SQLite、任意文件、平台 API 或其他源的数据。

## 4. 漫画源安装与管理

MVP 支持用户主动添加 `.js` 源。

流程：

```text
漫画源页
  -> 添加源
  -> 本地文件或 HTTPS URL
  -> 下载/读取 JS
  -> 解析 Manifest
  -> 校验 sourceApiVersion、域名和权限
  -> 用户确认
  -> 保存本地副本
  -> 启用
```

规则：

- 远程 URL 只用于下载安装，不可在每次执行时加载远端最新脚本；
- 同一 `sourceId` 只能有一个活动版本；
- 更新源时权限扩大必须重新确认；
- 删除源不删除用户已下载漫画图片和阅读进度；
- 源失败不得导致应用崩溃；
- 不建设官方公共漫画源市场。

`.msrc` 包格式保留为后续正式分发方案，但不是 Android MVP 的首要阻塞项。

## 5. 搜索与浏览

### 5.1 单源浏览

用户进入某个源后，可根据源能力展示：

- 热门；
- 最新；
- 分类；
- 筛选；
- 搜索。

这些能力由 Manifest 声明，未支持的入口不显示。

### 5.2 聚合搜索

用户可在漫画源页输入关键词并选择“全部已启用源”。

宿主为每个已启用且支持 `search` 的源独立调用：

```text
search(keyword)
```

要求：

- 单源失败不阻塞其他源；
- 结果必须携带 `sourceId` 和 `sourceMangaId`；
- 同名漫画默认保持独立；
- 点击结果后只调用产生该结果的同一个源；
- 不因标题相同自动切换来源或合并作品。

## 6. 详情与书架

漫画详情页展示：

- 标题；
- 封面；
- 作者；
- 简介；
- 状态；
- 标签；
- 章节列表；
- 来源信息；
- “加入书架/移出书架”。

加入书架后宿主保存：

- `sourceId`；
- `sourceMangaId`；
- 漫画元数据快照；
- 最后阅读章节；
- 页码；
- 阅读时间；
- 未读数量；
- 下载状态。

操作必须幂等，重复点击不会产生重复书架记录。

## 7. 阅读器

支持：

- 纵向连续；
- Webtoon；
- 从左到右；
- 从右到左；
- 原始尺寸；
- 适应宽度；
- 适应高度；
- 适应屏幕；
- 智能适应；
- 缩放、拖动、预加载；
- 本地保存阅读进度。

在线页和下载页使用相同渲染管线。

## 8. 下载与离线

支持：

- 单章下载；
- 多章下载；
- 书架批量选择漫画后创建下载计划；
- 暂停、继续、取消、失败重试；
- 下载完成后断网阅读；
- 应用重启后恢复任务状态。

正式下载与阅读缓存必须分离。

## 9. 数据与隐私

- 不建设账号系统；
- 不建设自有后端；
- 不上传书架、阅读历史和源列表；
- 结构化状态最终存入 SQLite/Drift；
- 图片和源文件保存在应用私有目录；
- 默认不集成广告、分析、崩溃上传和推送 SDK。

第三方漫画源站仍会看到用户向其发起的网络请求。

## 10. 明确不做

当前范围不包括：

- 内容站账号登录；
- WebView 登录；
- 验证码自动化；
- DRM、付费墙或地区限制绕过；
- APK、DEX、JAR、动态库漫画源；
- OCR；
- AI 翻译；
- 云同步；
- 社交功能；
- 自动识别并合并同名漫画；
- 桌面端。

## 11. 平台范围

| 项目 | 当前决定 |
|---|---|
| 主平台 | Android 10+ |
| UI | Flutter |
| JS 运行时 | 当前原型 `flutter_js`；目标为受限 JS Runtime Adapter |
| 本地数据库 | SQLite / Drift |
| 后台下载 | Android WorkManager |
| 发行 | GitHub APK / 自签构建优先 |
| iOS | 未来兼容，不进入当前 MVP 验收 |

## 12. MVP 成功标准

在 Android 真机完成：

1. 首页只显示“书架 / 漫画源 / 设置”三个一级入口；
2. 从漫画源页安装并启用至少一个 JS 源；
3. 从该源搜索漫画；
4. 打开漫画详情和章节列表；
5. 加入书架；
6. 从书架再次进入作品；
7. 在线阅读章节；
8. 下载章节并断网阅读；
9. 杀死应用并重启后恢复书架和阅读进度；
10. 一个失效 JS 源不会拖垮其他源或应用本身。
