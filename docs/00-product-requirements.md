# 产品需求与范围

文档状态：已确认  
版本：1.0  
日期：2026-08-01

## 1. 产品定义

Ayanami 是一个不经营、不托管内容的本地漫画阅读器。它向用户提供漫画源运行时、跨源搜索、书架、章节管理、在线阅读和下载能力。内容地址、解析规则和使用授权均来自用户主动安装的漫画源。

产品承诺的是“稳定、安全地执行源规则并阅读结果”，不承诺任何第三方源持续可用，也不提供绕过付费、登录、验证码、DRM 或访问控制的能力。

## 2. 目标用户与核心场景

目标用户希望在同一移动端应用中管理自己有权访问的多个漫画站点或自建内容服务。

核心闭环：

```text
导入漫画源
  -> 检查权限与签名
  -> 启用源
  -> 搜索或浏览
  -> 查看详情与章节
  -> 加入书架
  -> 在线阅读或下载
  -> 自动保存本地进度
```

## 3. 功能需求

### 3.1 漫画源管理

- 主界面提供独立“JS 源”按钮，与“设置”按钮并列；漫画源管理不属于设置页，设置页内不重复提供源入口。
- 点击“JS 源”进入专用源管理页，集中展示已安装源、启用状态、版本、签名状态和错误信息。
- 源管理页提供“通过 URL 添加”操作。用户输入 HTTPS URL 后，应用下载 `.js` 到临时区域，完成大小、编码、哈希、Manifest、权限与沙箱预加载校验，用户确认后才安装并加载本地副本。
- URL 只用于下载安装；运行时不得每次从 URL 直接执行最新响应，源升级仍需显式下载、校验和确认。
- 从本地文件或 HTTPS URL 导入单个 `.js` 或 `.msrc` 包。
- 安装前展示源 ID、名称、版本、作者、申请域名、权限、签名状态与风险。
- 支持安装、升级、降级确认、启用、禁用和删除。
- 同一 `sourceId` 只能有一个活动版本。
- 源升级不得静默扩大域名或权限；扩大时必须重新征得用户确认。
- 删除源时保留已下载图片和阅读进度，解除在线刷新能力。
- 无应用内源市场；源仓库仅作为用户主动配置的索引地址。

### 3.2 搜索与浏览

- 支持单源搜索和多个已启用源的并发聚合搜索。
- “发现”页是跨源搜索的统一入口。用户提交漫画名称后，宿主获取搜索开始时所有“已安装且已启用”的 JS 源，并把同一关键词分别传入各源的 `search` 函数。
- 各源的搜索状态和结果独立返回；慢源、空结果或失败源不得阻塞其他源。结果项必须携带 `sourceId`、`sourceMangaId` 和进入详情所需的源内引用快照。
- 用户点击搜索结果后，宿主根据该结果的 `sourceId` 定位原 JS 源，并调用该源的 `getMangaDetails` 获取详情、再调用 `getChapters` 获取章节。点击结果不得重新发起关键词聚合搜索，也不得把结果交给其他源解析。
- 单源失败不阻断其他源返回结果。
- 每条结果明确显示来源和语言，不以标题自动断言为同一作品。
- 支持源提供的热门、最新和筛选器能力；这些能力均为可选。
- 聚合搜索允许取消、超时、单源重试和按来源过滤。

完整交互、路由与状态约定见 [JS 源发现与详情流程](11-source-discovery-flow.md)。

### 3.3 详情与书架

- 展示标题、封面、别名、作者、简介、状态、标签和章节列表。
- JS 源漫画详情页必须提供醒目的“添加到书架”按钮。点击后以当前 `(sourceId, sourceMangaId)` 创建或复用本地 `Manga`、`SourceManga` 和 `LibraryEntry`，操作必须幂等。
- 已在书架中的作品显示“已加入书架”状态，不重复创建记录；用户可从该状态进入书架或执行移出书架操作。
- 同一作品可关联多个源，但首版只支持用户手动关联，不做标题自动合并。
- 保存默认阅读源、最后阅读章节、页码、阅读时间和未读数量。
- 更新检查仅在应用运行期间或平台允许的后台时间内执行，不承诺精确定时。
- 书架支持普通浏览和批量选择模式。用户可选择多部漫画后执行“下载”，应用为每部漫画解析下载范围并创建统一批次。

添加到书架和批量下载的完整交互见 [书架与批量下载流程](12-library-batch-download.md)。

### 3.4 阅读器

- 支持纵向连续、Webtoon、从左到右和从右到左阅读。
- 支持原始尺寸、适应宽度、适应高度、适应屏幕和智能适应。
- 阅读器控制层提供“页面适配”面板，用户可在阅读过程中切换适应宽度、适应高度等模式；选择立即作用于当前页面，并可保存为全局默认或当前漫画偏好。
- 支持缩放、拖动、旋转重排、预加载、裁边、亮度覆盖和方向锁定。
- 在线阅读单一章节时自动缓存当前位置之后的页面。默认磁盘预读窗口为后 5 页，允许设置为关闭或 1–20 页；窗口只在当前章节内滑动，不自动跨到下一章。
- 自动缓存与正式下载不同：缓存允许按容量策略清理，不表示章节已经完成离线下载。
- 在线页与已下载页使用相同渲染管线。
- 阅读进度必须本地、节流且可恢复地保存。

### 3.5 下载

- 支持单章、批量章节、暂停、继续、取消、失败重试和删除。
- 支持从书架批量选择多部漫画创建下载计划。默认范围为各漫画尚未完成下载的章节；确认页允许改为“全部章节”“最新 N 章”或逐部选择章节。
- 批量提交前展示所选漫画数、章节数、可得的大小估算、网络约束和剩余空间；大小未知时必须明确标注，不得伪造精确值。
- 一个漫画或章节失败不得阻断同一批次中的其他漫画；批次只用于统一观察和操作，底层仍拆分为可恢复的章节任务。
- 支持仅 Wi-Fi、并发数、重试次数和存储空间阈值设置。
- Android 使用持久后台工作；iOS 使用系统背景下载能力并接受系统调度限制。
- 下载产物可被应用离线阅读；首版不承诺导出为 CBZ/PDF。

### 3.6 设置与诊断

- 阅读器适配偏好、章节后续页缓存数量和下载约束全部保存在本地。源启停仍只在独立“JS 源”页面管理，不进入设置页。
- 提供源调用日志和下载失败原因；日志默认脱敏，不记录 Cookie、完整查询密钥或响应正文。
- 支持导出不含内容文件和私密状态的诊断包。

## 4. 非功能需求

### 4.1 性能

- 10,000 条书架/历史记录下，常用本地列表首次查询目标小于 300 ms。
- 阅读器前后至少各预加载 1 页，内存压力下允许自动缩减。
- 在线章节默认在磁盘缓存当前位置之后 5 页；计量网络、空间不足或用户关闭时不强制预读。
- 聚合搜索首批可用结果不等待所有来源结束。
- JS 调用、网络和图片解码不得阻塞 Flutter UI isolate。

### 4.2 可靠性

- 应用异常退出后，已完成的下载文件、下载队列和阅读进度可恢复。
- 数据库迁移必须可回滚或在升级前生成本地备份。
- 文件写入采用临时文件加原子重命名，数据库仅引用已完成文件。

### 4.3 隐私

- 不建设账号系统或自有后端。
- 不上传书架、历史、源列表、阅读内容或设备标识。
- 第三方源站仍会看到用户网络请求；安装页必须明确提示这一点。
- 默认不集成广告、分析、崩溃上传或推送 SDK。

### 4.4 可访问性与本地化

- 首发界面为简体中文，字符串必须从 UI 代码中抽离以支持后续本地化。
- 关键操作具备语义标签、动态字体和足够触控面积。
- 阅读器控制栏支持屏幕阅读器，但漫画图片本身不承诺无障碍文本。

## 5. 明确不做

- 应用账号、内容站账号登录、WebView 登录和验证码自动化。
- 自有云端、云同步、跨设备同步和社交功能。
- OCR、机器翻译、端侧大模型、云端模型和嵌字。
- 绕过 DRM、订阅、付费墙、地区限制或访问控制。
- APK、DEX、JAR、动态库、WebAssembly 或原生插件式漫画源。
- 任意文件系统、系统命令、通讯录、位置、剪贴板等源权限。
- 应用内支付、内容售卖或源作者分成。
- 首版自动合并同名漫画、CBZ/PDF 导出和桌面端。

## 6. 平台与发行范围

| 项目 | 决定 |
|---|---|
| 主平台 | Android 10+ |
| 兼容平台 | iOS 16+ |
| UI | Flutter |
| JS 引擎 | QuickJS，经 C API 嵌入 |
| 本地数据库 | SQLite，Flutter 层建议 Drift |
| 完整发行 | Android GitHub/自签版；iOS 自签或允许该能力的分发渠道 |
| 商店发行 | 使用单独 capability 配置；必要时仅支持内置/声明式源或本地文件 |

“兼容 iOS”表示代码和交互具备 iOS 实现，不等同于保证含远程 JavaScript 源能力的构建可以通过 App Store 审核。

## 7. MVP 成功标准

使用一个内置测试源和一个用户导入测试源，在 Android 与 iOS 测试设备上完成：

1. 安装并启用源；
2. 搜索漫画；
3. 打开详情与章节；
4. 加入书架；
5. 在线阅读；
6. 下载章节后断网阅读；
7. 杀死并重启应用后恢复进度与下载状态；
8. 恶意源无法访问未声明域名、本地网络、任意文件或原生 API。
