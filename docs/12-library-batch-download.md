# 书架与批量下载流程

状态：已确认、待后续实现  
适用范围：JS 源漫画详情、书架浏览和多漫画下载

## 1. 目标流程

```text
JS 源搜索结果
  -> 对应 JS 源详情与章节
  -> 点击“添加到书架”
  -> 宿主本地保存书架项
  -> 在书架浏览作品
  -> 进入批量选择模式
  -> 勾选多部漫画
  -> 点击“下载”
  -> 选择下载范围并确认
  -> 创建批次和章节下载任务
```

## 2. 详情页“添加到书架”

按钮位于 JS 源漫画详情页的主要操作区，与“开始阅读”等主要动作同级。按钮状态：

```text
notInLibrary -> adding -> inLibrary
                     \-> failed
```

- `notInLibrary`：显示“添加到书架”。
- `adding`：阻止重复提交并显示进度。
- `inLibrary`：显示“已加入书架”，可进入书架或从更多菜单移出。
- `failed`：保留详情内容，显示可重试错误。

写入请求：

```typescript
interface AddToLibraryCommand {
  sourceId: string;
  sourceVersion: string;
  sourceMangaId: string;
  detailsSnapshot: MangaDetails;
  chapterSnapshot: Chapter[];
}
```

宿主以 `(sourceId, sourceMangaId)` 幂等创建或复用 `SourceManga`，再创建或复用 `Manga` 和 `LibraryEntry`。按钮不调用 JS 源的收藏接口，也不向第三方站点同步收藏。

章节尚未加载完成时允许先加入书架，但应保存详情快照并把章节刷新标记为待处理。源不可用时，已加入的本地书架项仍保留。

## 3. 书架浏览

普通模式支持打开详情、继续阅读、查看未读/下载状态和排序筛选。每张漫画卡片使用稳定 `libraryEntryId`，不得用当前列表位置识别。

进入批量选择模式的方式：

- 长按任意漫画卡片；或
- 点击书架工具栏中的“批量选择”。

选择模式行为：

- 点击卡片切换选中状态，不进入详情；
- 工具栏显示已选择数量、全选当前筛选结果、取消和“下载”；
- 排序或视图样式变化不丢失选择；
- 改变筛选条件时，隐藏项仍保持选择，但确认页必须显示最终作品清单；
- 已从书架移除的项在提交时自动排除并提示。

## 4. 批量下载范围

点击“下载”后先进入确认页，不立即入队。默认范围：

```text
每部漫画的未下载章节
```

可选范围：

| 范围 | 行为 |
|---|---|
| 未下载章节 | 排除已经完整下载的章节；默认 |
| 全部章节 | 包含所有可用章节，已完成项仍复用而不重下 |
| 最新 N 章 | 每部漫画分别取最新 N 个可用章节 |
| 逐部选择 | 为每部漫画选择具体章节或区间 |

“未读”与“未下载”不是同一概念。默认使用未下载，避免用户已阅读但尚未离线保存的章节被遗漏。

## 5. 确认摘要

提交前显示：

- 已选漫画数量和名称；
- 各漫画采用的来源；
- 待创建的章节任务数量；
- 已下载、已有活动任务和将新建任务的数量；
- 可得的总大小估算及“部分大小未知”标记；
- 当前剩余空间和最低保留阈值；
- 仅 Wi-Fi、充电要求、并发等约束；
- 无法解析章节或来源不可用的漫画。

大小未知时允许继续，但必须明确提示。预计空间明显不足时默认阻止提交，用户调整范围或清理空间后重试。

## 6. 创建批次

```typescript
interface CreateLibraryDownloadBatchCommand {
  libraryEntryIds: string[];
  scope:
    | { type: "notDownloaded" }
    | { type: "all" }
    | { type: "latest"; count: number }
    | { type: "selected"; chapterIdsByLibraryEntry: Record<string, string[]> };
  constraints: DownloadConstraints;
}
```

提交采用两段式流程：

1. `prepare` 刷新/读取章节、解析范围并生成只读计划；
2. 用户确认计划版本后，`commit` 创建 `DownloadBatch` 和章节级任务。

若确认前章节清单发生变化，提交返回“计划已变化”，展示差异后重新确认，避免静默扩大下载范围。

## 7. 失败隔离和批次控制

- 一部漫画的源失效不阻断其他漫画创建任务。
- 单章节失败只影响该章节和批次汇总状态。
- 批次可暂停、继续或取消尚未完成的子任务。
- 取消批次不删除已经完成的章节。
- 已存在的活动章节任务被复用，不创建并行重复任务。
- 批次完成可以是全部完成或部分完成；部分完成必须列出失败漫画与章节。

## 8. 验收条件

- JS 源漫画详情页显示“添加到书架”，成功后显示“已加入书架”。
- 同一来源漫画重复添加不会产生重复书架项。
- 书架可通过长按或工具栏进入批量选择并选择多部漫画。
- 选择在排序和列表刷新后仍绑定正确作品。
- 点击下载先显示确认页，默认范围是未下载章节。
- 用户可改为全部、最新 N 章或逐部选择章节。
- 提交后产生一个批次和多个章节任务，已有任务/下载不重复创建。
- 单个来源失败不取消其他漫画任务。
- 暂停或取消批次不删除已经完成的章节。
