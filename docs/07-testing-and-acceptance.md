# 测试与验收

## 1. 测试策略

采用测试金字塔：领域和解析逻辑以快速单元测试为主；数据库、文件、JS Host API 和平台适配器使用集成测试；关键用户闭环使用真机端到端测试。真实第三方网站只用于人工兼容验证，不作为稳定 CI 依赖。

## 2. 测试层级

### 2.1 单元测试

- ID、SemVer、BCP 47、URL 和 Manifest 校验；
- 域名通配、IDN、私网地址和重定向判断；
- 章节排序、进度覆盖和多源关联；
- 五种缩放算法与旋转后位置换算；
- 下载状态机、重试分类和幂等逻辑；
- 路径规范化、文件引用计数和缓存淘汰；
- 包规范化哈希与签名验证。

### 2.2 组件/集成测试

- QuickJS 封装与所有 Host API；
- SQLite Schema、约束、事务、迁移与损坏恢复；
- `.msrc` 解包、升级、回滚和权限差异；
- Mock HTTP Server 下的 Cookie、Header、分页、限速和超时；
- 下载续传、ETag 变化、临时文件和原子移动；
- Reader Widget 的手势、缩放、方向和进度保存；
- Android WorkManager 与 iOS background URLSession 适配层。

### 2.3 端到端测试

```text
导入测试源 -> 搜索 -> 详情 -> 收藏 -> 阅读 -> 下载
-> 断网 -> 重启 -> 离线阅读 -> 删除下载 -> 卸载源
```

Android 至少覆盖 API 29 和当前目标 SDK 对应的新系统版本；iOS 至少覆盖 iOS 16 和当前主版本。每个平台包含低内存设备或等效压力配置。

## 3. 固定测试源

CI 中运行本地确定性站点和源夹具：

| 夹具 | 覆盖 |
|---|---|
| `static-html` | CSS 选择器、相对 URL、详情和章节 |
| `json-api` | JSON 响应、游标分页 |
| `referer-images` | 图片请求头 |
| `expiring-url` | 页面请求重新解析 |
| `slow-source` | 取消、超时、流式聚合 |
| `schema-invalid` | 所有返回模型边界 |
| `malicious-runtime` | 无限循环、递归、内存和日志炸弹 |
| `malicious-network` | SSRF、跳转、DNS rebinding |
| `malicious-package` | ZIP Slip、重复路径、超大解压、坏签名 |

测试源的远端 HTML/JSON 快照进入仓库，确保源站改版不导致 CI 随机失败。

## 4. 功能验收

### 源管理

- [ ] 主界面“JS 源”按钮与“设置”按钮并列，设置页内不存在源管理入口。
- [ ] 从“JS 源”页输入 HTTPS URL 后，应用先下载临时 `.js`，校验并展示权限，只有确认后才安装和加载本地副本。
- [ ] URL 重定向到 HTTP、私网、loopback、超大响应、非 UTF-8 或非文本内容时拒绝安装。
- [ ] 取消确认或校验失败不会改变已安装源，且临时文件被清理。
- [ ] 已安装源运行时不重新获取 URL 当前内容；更新必须再次确认。
- [ ] `.js` 与 `.msrc` 的允许/禁止规则符合当前构建能力。
- [ ] 安装前可看到权限、域名、版本和签名状态。
- [ ] 权限扩大、密钥变化和降级都不能静默发生。
- [ ] 禁用源后所有新调用被拒绝；删除源不删除正式下载。
- [ ] 上一版本可回滚且源级数据按规则保留。

### 搜索、详情与书架

- [ ] 发现页提交名称时，只调用搜索开始时已安装且已启用源的 `search`。
- [ ] 多源搜索逐源返回，慢源/坏源不阻断其他结果。
- [ ] 取消搜索后不再更新已销毁页面状态。
- [ ] 每条结果始终显示来源；同名结果不自动合并。
- [ ] 搜索结果携带稳定的 `(sourceId, sourceMangaId)`，点击后只调用原来源的 `getMangaDetails` 和 `getChapters`。
- [ ] 点击搜索结果不会重新运行关键词搜索，也不会把结果传给其他源解析。
- [ ] 结果产生后源被禁用、删除或升级时，详情页显示可恢复错误，不静默切换来源。
- [ ] 章节刷新幂等，不因标题变化制造无意义重复记录。
- [ ] JS 源漫画详情页显示“添加到书架”，点击后创建书架项并切换为“已加入书架”。
- [ ] 对同一 `(sourceId, sourceMangaId)` 重复点击不会创建重复 `Manga`、`SourceManga` 或 `LibraryEntry`。
- [ ] 加入书架是本地宿主操作，不调用 JS 源写入收藏状态。
- [ ] 书架批量选择在排序、筛选和列表刷新后仍指向正确 `libraryEntryId`。
- [ ] 收藏、取消收藏和手动关联来源符合删除语义。

### 阅读器

- [ ] 四种阅读方向和五种缩放模式符合公式。
- [ ] 阅读中可打开页面适配面板并切换适应宽度、适应高度、适应屏幕、原始尺寸和智能适应。
- [ ] 适配偏好按本次会话、当前漫画、全局默认的优先级持久化，JS 源不能覆盖。
- [ ] 缩放时不误翻页；横竖屏切换保持当前页面。
- [ ] 在线、本地缓存和正式下载走同一渲染行为。
- [ ] 默认阅读页 `i` 时低优先级缓存同章后 5 页，移动到下一页后窗口随之前移且不跨章节。
- [ ] 后续页数量可设置为关闭或 1–20；计量网络禁止、空间不足、离开章节和禁用源时停止新预读。
- [ ] 内存预加载与磁盘缓存可独立释放，缓存清理不改变章节正式下载状态。
- [ ] 正式下载可复用已验证缓存，且不会重复请求同一页。
- [ ] 单页失败可重试，不导致整章退出。
- [ ] 杀进程和重启后恢复章节、页码和页内位置。

### 下载

- [ ] 单章、批量、暂停、继续、取消、重试和删除可用。
- [ ] 书架可勾选多部漫画并创建一个批量下载确认计划，默认只包含未下载章节。
- [ ] 确认页允许选择全部、最新 N 章或逐部章节，并展示已知大小、未知大小、网络约束和空间信息。
- [ ] 某部漫画源不可用时不阻断其他已选漫画；失败项在确认页明确列出。
- [ ] 批次拆分为章节级幂等任务，已有活动任务被复用，已完成章节不重复下载。
- [ ] 暂停、继续或取消批次不会删除已经完成的章节。
- [ ] 同章节重复点击不会创建并行重复任务。
- [ ] 进程死亡、网络切换和系统回收后状态可协调恢复。
- [ ] 空间不足、伪装 HTML、哈希异常和过期 URL 有明确错误。
- [ ] 清缓存不删除正式下载；卸载源不破坏离线阅读。

## 5. 安全验收

- [ ] 源不能访问未声明域名、任何私网地址或非 HTTPS 协议。
- [ ] 每个重定向跳转重新校验，DNS 地址变化不会绕过限制。
- [ ] 源不能读取其他源存储、应用数据库或任意文件。
- [ ] 无限循环在预算内终止，应用 UI 继续响应。
- [ ] 超大返回、深层 JSON、恶意 HTML 和图片不会导致宿主 OOM。
- [ ] 日志、错误弹窗与诊断包不包含 Cookie 和测试密钥。
- [ ] 渠道构建中被禁用能力从二进制/入口层不可到达，而非仅隐藏 UI。

## 6. 性能验收

在项目确定的基准设备和固定夹具上记录，而不是用开发机感受替代：

- 冷启动、书架首屏和 10,000 条数据库查询耗时；
- 20 个源并发搜索的首结果和完成时间；
- 200 页章节持续滚动的帧时间、峰值内存和泄漏趋势；
- 100 页下载的吞吐、CPU、耗电和中断恢复；
- 恶意源达到资源上限时的终止延迟。

目标值以 `00-product-requirements.md` 为最低门槛；基准结果进入版本发布记录。

## 7. 数据迁移验收

每个 Schema 版本必须测试：

1. 从所有仍受支持的旧版本升级；
2. 中途失败后原数据仍可恢复；
3. 重复运行迁移不会重复写入；
4. 下载文件引用在迁移后仍有效；
5. 新版本导出的数据带明确 Schema 版本。

## 8. 发布阻断条件

以下任一存在时不得发布：

- 可复现的沙箱逃逸、SSRF、任意文件访问或签名绕过；
- 数据库迁移可能静默清空书架/进度；
- 删除或清缓存可能越过应用内容目录；
- 进程重启普遍造成已完成下载丢失或重复下载；
- 当前渠道构建包含其政策明确不允许的能力；
- 许可证、隐私说明或第三方依赖来源不清楚。

## 9. 完成定义

功能只有在以下条件全部满足时才算完成：代码、自动化测试、错误状态、无障碍标签、文档、数据库迁移（若有）、诊断信息和相关真机验收均已完成。仅在开发设备上展示成功不算完成。
