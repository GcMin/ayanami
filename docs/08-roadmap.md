# 实施路线图

路线图按可验收里程碑排序，不给出未经团队容量验证的日期承诺。每一阶段必须满足退出条件后再扩大范围。

## M0：工程骨架与风险验证

交付：

- Flutter Android/iOS 工程和分层目录；
- SQLite/Drift 基础 Schema 与迁移框架；
- QuickJS C ABI 最小封装和 Dart FFI；
- 内存限制、执行中断、超时和取消验证；
- 本地 Mock Server 与第一个静态测试源；
- Android/iOS CI 构建、单元测试和格式检查。

退出条件：恶意无限循环能被终止，Flutter UI 不冻结；测试源可通过 JS 返回一个经过 Schema 校验的搜索结果。

## M1：漫画源安装与内容发现

交付：

- `.js` 开发导入；
- 与“设置”并列的独立“JS 源”入口和源管理页面；
- 通过 HTTPS URL 下载 `.js`、临时校验、权限确认并加载本地副本；
- `.msrc` 安全解包、Manifest、哈希和签名状态；
- 权限/域名确认、启用、禁用、删除、升级和回滚；
- HTTP、HTML、JSON、URL、Storage Host API；
- 发现页将关键词并发传入所有已启用源的 `search`，逐源汇总结果；
- 结果携带来源路由键，点击后调用同一源的 `getMangaDetails` 与 `getChapters`；
- 源日志和错误诊断。

退出条件：源 SDK 固定夹具全部通过；SSRF、路径穿越、资源炸弹和权限升级测试通过。

## M2：书架与基础阅读器

交付：

- 书架、历史、手动多源关联；
- JS 源详情页“添加到书架”按钮和幂等书架写入；
- 书架批量选择模式及稳定选择状态；
- 在线页面加载与图片缓存；
- 四种阅读方向、五种缩放模式；
- 阅读器页面适配面板及会话/作品/全局三级偏好；
- 单章节后续页滑动缓存窗口、网络约束和 LRU 回收；
- 缩放/拖动/翻页、旋转恢复和进度保存；
- 页面错误占位、预加载和内存压力处理。

退出条件：完整完成导入—搜索—收藏—在线阅读；200 页夹具无持续内存增长，进程重启恢复进度。

## M3：持久下载与离线阅读

交付：

- 下载队列、状态机和文件布局；
- 单章/批量、暂停/继续/取消/重试；
- 从书架选择多部漫画，按未下载/全部/最新 N 章/指定章节创建下载批次；
- 批次确认摘要、部分失败和批次级暂停/继续/取消；
- Android WorkManager 适配；
- iOS background URLSession 适配；
- 下载协调恢复、空间检查、缓存管理和完整性扫描。

退出条件：下载中杀进程、断网、换网、磁盘不足和 URL 过期场景全部通过；断网可完整阅读已下载章节。

## M4：产品化与发行分层

交付：

- Android 自签/GitHub 完整构建；
- Google Play 能力配置和政策复核；
- iOS 完整能力的允许渠道构建；
- iOS App Store 受限能力构建；
- 隐私说明、开源许可证、诊断导出和安全响应流程；
- 性能基线、模糊测试和真机矩阵。

退出条件：不同渠道的不可用能力在编译时排除；安全与发布门槛全部通过。

## 后续候选项

以下内容不属于当前承诺，必须新建 ADR 和产品评审：

- CBZ/PDF 导入导出；
- 自动同作品识别与章节映射；
- WebDAV 或其他同步；
- 桌面端；
- 声明式数据源格式；
- OCR、翻译或任何 AI 能力；
- 内容站登录、WebView 验证或 DRM 相关能力。

## 工作拆分原则

- 优先完成纵向切片，不先制作大量静态页面。
- 安全边界和错误路径与正常功能同期实现。
- 固定测试源先于真实站点适配。
- 平台后台任务从 M0 建立原型，避免到 M3 才发现架构不可行。
- 每个里程碑结束更新性能数据、风险表和决策记录。

## 当前首个开发任务

建议从 M0 的 QuickJS 风险探针开始：实现一个不接触网络和数据库的原生插件，验证 Android/iOS 的加载、模块执行、内存上限、中断、异常映射和并发取消。该结果决定运行时应使用工作线程还是独立进程，是后续架构的最高风险前置项。
